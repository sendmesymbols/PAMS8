## New file: ground-guide-decision-board.html

Created `D:\Projects\Web\PAMS8\ground-guide-decision-board.html` — a single-screen
"decide at a glance" board. Self-contained HTML/CSS/vanilla JS, no network or
build, light + dark themes, inline SVG only.

Design principle: verdict first, six headings second, evidence on demand.
Contents: doctrine strip; controls for 5 sample places / 14 modes / 12 months;
clickable rainfall ribbon (wet threshold from monthly normals); hero with a
six-axis coverage radar, a one-line decision slip, GO/SLOW-GO/NO-GO scale and a
"rain changes this answer" chip; six letter cards with status pills and a
click-to-open evidence table; "What changes the answer" and "Where the data stops"
panels; and a 10-row decision table collecting the recommended default from each
option page with Copy / Reset.

Reuses the coverage map's design language (Barlow Condensed / IBM Plex, the six
letter colours, the on/sw/part/data/miss status pills, rules 2026.11-grotbc-v2).
All figures are labelled illustrative. Data honesty wording ("Modelled",
"Where Recorded", "WorldPop Estimate") is carried through.

Validated with `node --check` on the embedded script and headless Chrome
(`--dump-dom` + `--screenshot`): render, all control changes, letter detail,
decision chips, copy/reset, theme toggle, and repeat-render idempotence all pass.
