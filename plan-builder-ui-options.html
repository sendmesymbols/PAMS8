Intelligent Deployment: a calmer, clearer tab

Same five steps, same words, same keys and logic. CSS plus small markup changes in PlanBuildTab.ts, scoped to this tab so other widgets keep their look. Click anything in either panel: both follow the same step and choices. Drag a panel's bottom edge to make it taller.

Theme

Content is what the live tab showed for Defence, Bn Def two up. Other operations select but do not change the content. The Check step uses sample fitted figures so that every verdict shows.

What changes

Thirteen changes, none to the logic. Each names where it lands.

    The parts

    Every control the tab uses, in every state, in the theme picked above. One vocabulary: the same radius, height and selected look for segments, chips and buttons.

    Not changed

    • The five steps, their order, Build a plan and Check my plan.
    • Every word of doctrine, every reason, Why and Fix as the engines write them.
    • The keys while placing (M, P, R, T, J, Shift+J, Esc, Ctrl+Z).
    • The solver, the fit, the checks and the map graphics.
    • The panel's header, the Templates tab and every other widget: .ms-btn keeps its look outside this tab.
    • The cursor card while placing: it could follow in the same style later, not part of this.
