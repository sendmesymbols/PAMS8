How FlowRenderer works
The layer must serve a two-band raster: band 1 = U (east) component, band 2 = V (north) component, both in m/s. FlowRenderer animates streamlines from those vectors — no server-side processing required. // Key requirement: U/V bands in m/s renderer.flowType = "vector"; // or "magnitude"

Substituting your own vector raster
The pixelFilter function intercepts every pixel block before rendering. Override the U/V values with your own model and FlowRenderer animates your field — no server, no hosted raster required. layer.pixelFilter = ({ pixelBlock, extent }) => { // pixelBlock.pixels[0] = U component array // pixelBlock.pixels[1] = V component array // Write your model output here ↓ };
