Architecture notes

CIMPointSymbol contains an ordered symbolLayers[] array. Layers render bottom-to-top — cone first, then arrow, then baseplate.

Radial indicator is a CIMVectorMarker whose markerGraphics contains a line path from (0,8) to (0,44) in frame space, pointing up (+Y). Setting rotateClockwise: true with rotation: bearing orients it geographically.

Tapered cone is a polygon wedge with apex at (0,0) and arc points at radius R. A fan of 24 vertices along the arc gives smooth curvature. Frame +Y = up; rotation aligns it to bearing.

colorMixMode on the cone fill uses "multiply" so it composites over the base map rather than occluding it.

Production rotation: instead of rebuilding CIM JSON on bearing changes, set rotation: 0 on all layers and add a renderer visualVariable of type "rotation" driven by a feature attribute. The entire symbol rotates as one.

billboardMode3D = "FaceNearPlane" keeps the symbol upright in SceneView regardless of camera tilt — correct for tactical overlays.

Dashed dead-zone ring uses CIMGeometricEffectDashes on the stroke layer — a CIM geometric effect applied per-layer, not per-symbol.
