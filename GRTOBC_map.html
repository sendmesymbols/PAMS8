GROTBC Card Map

What the Ground Guide cursor card shows (MS/Engines/GroundGuide/), arranged under the GROTBC headings of GROTBC.md. Each item gives its data type (the value and where it comes from) and how it is shown now, with the default settings of MS/Data/Settings.json. Items the card shows outside the six letters (the placement verdict, W weather, admin and grid) have been given the GROTBC heading that fits them best. Where that is not the letter the card puts them under today, the item says so. Read from the code on 6 Nov 2026 (commit 04f5407).

How it is shown

    Data types: Category = a coded class with fixed labels from rules.json; Rating = GO / SLOW-GO / NO-GO; Level = None / Poor / Fair / Good; Nearest feature = name and kind of the closest mapped feature with its distance (m or km) and 8-point compass direction from the symbol. Raster sources are the bundle's terrain tile layers; Feature sources are the vector tiles in features/ (kind numbers as in features/index.json). "Detail grid" rows show by default because sections.detail is on; with sections.style: lines the same rows show as full rows instead of under a one-line summary. Every card item is also in the Ground Brief (G key) and in Copy as Text.
