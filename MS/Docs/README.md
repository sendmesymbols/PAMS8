# PAMS8 Symbol Library - Developer Guide and Technical Reference

PAMS8 draws MIL-STD-2525D tactical symbols on ArcGIS maps (2D `MapView` and 3D `SceneView`) and adds editing, measurement, decluttering, analysis, briefing and collaboration tools on top. This guide is for developers who consume the **built library** (`dist/MS`, minified `.min.js` plus `.d.ts` declarations), not the source.

## Where this documentation comes from

- Chapters 01-12 and 14 are hand-written Markdown in `MS/Docs`, checked against the source. Each chapter flags places where the source is ambiguous or inconsistent.
- Chapter 13 is generated from `MS/Data/Symbols.json`.
- The **API reference** (classes, methods, types) is generated by TypeDoc from the `.ts` sources.
- `npm run build` produces everything into `dist/MS/Docs`.

## What ships in `dist/MS/Docs`

| Path | Content |
| --- | --- |
| `dist/MS/Docs/index.html` | Searchable HTML site: guide chapters plus generated API reference |
| `dist/MS/Docs/markdown/` | The raw Markdown chapters, readable in any editor or Git viewer |

## Maintaining the documentation

| Command | Effect |
| --- | --- |
| `npm run docs:catalog` | Regenerate `13-symbol-catalog.md` from `Symbols.json` |
| `npm run docs:api` | Build the TypeDoc HTML site into `dist/MS/Docs` (the chapters must exist) |
| `npm run copy-docs` | Copy `MS/Docs` into `dist/MS/Docs/markdown` |
| `npm run docs:build` | All three, in that order |
| `npm run build` | Library build; runs `docs:build` after the other `copy-*` steps |
| `npm run dev:dist` | Library build plus `copy-docs` only (skips the slower TypeDoc step) |

Notes:

- `vite build` empties `dist/MS` (`emptyOutDir`), so docs are always copied **after** it. Keep them last in the chain.
- `docs:api` cleans `dist/MS/Docs` before writing. `copy-docs` must therefore run after it, which `docs:build` guarantees.
- New public methods appear in the API reference automatically. Add a `/** ... */` TSDoc comment to them so the reference has descriptions, and update the matching chapter when behaviour changes.

## Conventions

- Members prefixed with `_` are internal, even where TypeScript marks them public. Do not call them from host code unless a chapter says so.
- Live Web Mercator views report wkid **102100**, not 3857. See [04](04-support-classes.md).
- `@arcgis/core` is an external peer dependency (5.0.19). It is not bundled.
